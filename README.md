# Suno-Beat

（ゲーム画面上の仮タイトルは「STEM.BEAT」）
Sunoで作った曲を、パート分離して自動で譜面にし、ブラウザで遊べる音楽ゲームにするプロジェクト。
スマホ（横持ち）とPCで遊べる。画面の奥から譜面が迫ってくる4レーン方式。

## 仕組み

1. **曲を取ってくる**：Suno MCPでWAVをダウンロード（ダウンロード枠を1つ使う）
2. **パート分離**：Demucs（`htdemucs`の4パート版）でドラム／ベース／その他／ボーカルに分ける
3. **譜面生成**：`pipeline/chart.py`
   - ビートを推定し、実際のドラムの立ち上がりに合わせてずれを補正（実測でほぼ6ms以内）
   - ドラムを低音と中音の比率でキック／スネアに分け、高音でハイハットを拾う
   - ギターは「音の鳴り始め」と「コードが変わった瞬間」の両方から拾う
   - 難易度ごとの目標密度（EASY 1.8 / NORMAL 3.5 / HARD 5.5 ノーツ毎秒）に自動で合わせる
4. **遊ぶ**：`web/`（元のミックスをそのまま再生し、タップすると効果音が鳴る）

レーン：KICK / SNARE / HAT / GUITAR（PCのキーはD F J K）。ボーカルはレーンにしない方針。

## フォルダ

| 場所 | 中身 |
|---|---|
| `web2/` | **新しい版（開発の本線）**：縦持ち。壁で跳ね返りながら落ちてくる球を、下のラインの同じ位置でタッチして打ち返す |
| `web/` | 最初の版（横持ち・奥から迫る4レーン）。参考として残している |
| `songs/<slug>/` | 曲ごとの譜面と音源 |
| `pipeline/` | 分離と譜面生成のスクリプト |
| `tests/play_test.js` | Playwrightで縦持ち・横持ち・PCを自動プレイして確認するテスト |

## 曲を追加する

```bash
pip install torch torchaudio --index-url https://download.pytorch.org/whl/cpu
pip install -r pipeline/requirements.txt
pipeline/build_song.sh path/to/song.wav my-song "My Song"
# 譜面だけ作り直す: python3 pipeline/chart.py <stems_dir> "Title" out.json [disc|lanes]
```

## 新しい版（web2）の仕組み

- **Suno MCPで作った曲は、Sunoの解析を使う**（`--suno=songs/<slug>/suno.json`）：拍・拍子はSunoの拍、歌っている区間とフレーズの頭はSunoの歌詞タイミング。自前の推定はMCP以外の曲用の予備（その時は `--bpm=` でテンポの目安を渡す。音だけだと倍・半分を間違えやすい）
- **密度は「1拍あたり」で決め、毎秒の上下限で抑える**：EASY 0.30/拍（0.5〜1.0/秒）、NORMAL 0.55/拍（0.9〜1.8/秒）、HARD 1.0/拍（1.6〜3.2/秒）。同時押しはノーツ全体の NORMAL 6% / HARD 12% まで、EASYはなし。2小節（8拍）以上ノーツが来ない所は、置ける候補があれば埋める
- 遅い曲（16分の間隔が0.14秒以上）は16分の位置も使う（EASYは歌い出しだけ）
- 検証：`pipeline/compare.py <slug>...` でSunoの解析と突き合わせる（`songs/SAMPLES.md` の6曲）
- **譜面の方針（`pipeline/chart.py` の `disc` プロファイル）**
  - 歌メロ（ボーカルの音節）がノーツの主役。歌は自然にまばらなので、ノーツ数が抑えられる
  - 楽器（キック／スネア／ハイハット／ギター）のノーツは、歌っていない所（間奏・フレーズの隙間、前後1拍あける）にだけ置く
  - 最初の版用の密な譜面は `lanes` プロファイルで今まで通り作れる
- ディスクは大きく、当たり範囲はディスク半径の1.5倍。落下速度は難易度と無関係で、プレイヤーの設定だけで変わる
- 同時押しは白い線でつなぎ、2枚並んでほぼまっすぐ落ちてくる（空中で交差しない）
- 打ち返したディスクは、落ちてきた時と同じ速さで相手側へ戻る（対戦時に相手が読めるように）
- 譜面（タイミング＋パート）から、ディスクごとに着地位置と跳ね返り回数を決めて軌道を計算する（同じ譜面なら毎回同じ動き）
- 間隔が短い連続ノーツは近い位置に着地させ、同時ノーツは十分離す
- 判定はタイミングと位置の両方。打った球は相手側へ飛んでいく
- 色と大きさはパートごと（キック／スネア／ハイハット／ギター）
- 既存の作品の名前・ロゴ・見た目・効果音は使わない方針（遊び方のオマージュに留める）
